# Dış Cephe Renklendirme

F Blok için Three.js ile hazırlanmış 3B cephe renk stüdyosu. Tek dosya (`index.html`), derleme gerektirmez.

- Duvar, vurgu bantları, balkon, çatı, doğrama, korkuluk ve çevre renkleri canlı değiştirilir
- Hazır paletler, rastgele palet, gün saati/gölge, kamera ön ayarları
- Cepheye tıklayarak o yüzeyin renk seçicisine ulaşılır

Çalıştırma: `index.html` dosyasını tarayıcıda açın (Three.js r128 CDN'den yüklenir).
